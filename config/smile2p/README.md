# SMILE-2+用の設定

SMILE-2+の解析設定をこのフォルダにまとめています。
SMILE-3の第1段階・第2段階の設定は、それぞれ [stage1](../stage1/)・[stage2](../stage2/) にあります。

| 設定 | 用途 |
| --- | --- |
| [smile2p_20190701_Per02.json](smile2p_20190701_Per02.json) | Per02の地上較正データの再構成 |
| [smile2p_20190701_Per03.json](smile2p_20190701_Per03.json) | Per03の地上較正データの再構成 |
| [smile2p_sim_d10_recon.json](smile2p_sim_d10_recon.json) | シミュレーションデータの再構成 |
| [tpc_caldata_2017_Ba133.json](tpc_caldata_2017_Ba133.json) | Ba-133のTPC較正データ |

設定名だけでも実行できます。明示パスを使う場合は `config/smile2p/<設定名>.json` を指定してください。
